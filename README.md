# AI Skills Before 2027 — visual asset handoff

This public repository is a handoff between Grok Bot (asset research) and Claude Code (video production) for **4 AI Skills to Learn Before 2027 (So You Don't Fall Behind)**.

## Current contents

- `SCRIPT_LOCKED.md` — the supplied English narration. Keep its spoken text unchanged unless the creator approves a revision.
- `GROK_BOT_ASSET_PROMPT.md` — copy into Grok Bot and attach the locked script. Grok Bot should return a rights-checked asset package and a beat-level map.
- `CLAUDE_CODE_START_HERE.md` — copyable production instruction for Claude Code once Grok Bot's outputs are present.

No third-party media has been vetted or uploaded yet. The `assets/` folder should contain only files whose raw redistribution on a public GitHub repository has been verified. Other usable media belongs in a link-only or local-only list with its exact license conditions.

## Claude Code handoff

Read `SCRIPT_LOCKED.md` and `GROK_BOT_ASSET_PROMPT.md`. After the Grok Bot package is added, inspect `asset_manifest.csv`, `shot_asset_map.csv`, `SOURCES_AND_RIGHTS.md`, and the actual files before editing. Align visuals to the narration in order; preserve the hypothetical nature of the workplace example. Recreate unlabeled or unlicensed interface visuals as clearly marked illustrations. Render a 16:9 1080p review, inspect it, then export the final video with captions, editable source, a final asset manifest, and a QA note.

The narration has about 827 spoken words. At 130–150 words per minute, speech alone is roughly 5.5–6.4 minutes. A natural edit may be below the desired 7–9 minutes. Measure the actual voice track and report the projected duration before building the full edit; do not pad scenes to hide a short script.
